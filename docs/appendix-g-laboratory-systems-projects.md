# 附录 G 实验：系统项目

> 英文原题：*Laboratory: Systems Projects*

本附录给出一些系统项目思路。作者通常在一个 15 周学期中安排六七个项目，大约每两周一个；前几个一般由学生独立完成，后几个则两人组队。

每学期沿用同一大纲，但会改变细节以保持趣味，也让跨学期“共享”代码更困难——当然，怎么会有人做那种事呢！作者还使用 Moss 工具 [M94] 查找这种“共享”。

评分方法试过很多种，各有优缺点。现场演示有趣，却很耗时间；自动测试脚本省人力，但必须精心设计，才能真正覆盖有意思的边界情况。项目详情见本书网站；如果需要自动测试脚本，作者也乐于分享。

## G.1 入门项目

第一个项目用于介绍系统编程。典型作业是实现某种 `sort` 工具，并施加不同限制，例如排序文本数据、二进制数据等。完成项目需要熟悉少量系统调用及其错误返回码，使用几个简单数据结构，除此之外没有太多花活。

## G.2 UNIX Shell

学生构建一种 UNIX shell，学习进程管理，并揭开管道、重定向之类神秘事物的工作原理。

变体可以加入不同寻常的功能，例如一种重定向符号，在重定向输出的同时通过 `gzip` 压缩；也可实现批处理模式，积攒若干请求后再执行，甚至采用不同调度策略。

## G.3 内存分配库

通过实现另一套类似 `malloc()`、`free()` 但名称不同的内存分配库，探索一块内存怎样管理。学生用 `mmap()` 取得一块匿名内存，再深入操练指针，构造简单或更复杂的空闲链表。变体包括最佳适配、最差适配、伙伴系统以及其他分配器。

## G.4 并发入门

这个项目用 POSIX 线程介绍并发编程。可以构建一些线程安全库：链表、散列表及更复杂的数据结构，都是给真实代码加锁的好练习。还应测量粗粒度与细粒度方案的性能。不同变体可以换用不同、也许更复杂的数据结构。

## G.5 并发 Web 服务器

这个项目在真实应用中探索并发。学生取得一个简单 Web 服务器（也可以自己写），加入线程池以并发服务请求。线程池大小固定，主线程与工作线程池之间使用生产者/消费者有界缓冲区传递请求。借此学习怎样用线程、锁和条件变量构建真正的服务器。变体可要求不同的线程调度策略。

## G.6 文件系统检查器

这个项目探索磁盘数据结构及其一致性。学生构建简单的文件系统检查器；在 Linux 上可用 `debugfs` 制作真实文件系统镜像，遍历镜像并确认一切正常。提高难度时，还要修复发现的问题。不同变体可关注指针、链接计数、间接块使用等不同错误。

## G.7 文件系统碎片整理器

这个项目探索磁盘数据结构及其性能影响。教师提供存在已知碎片问题的文件系统镜像；学生遍历镜像，找出未顺序布局的文件，再写出修复问题的新“无碎片”镜像，并可顺便报告统计信息。

## G.8 并发文件服务器

这个项目把并发、文件系统，以及一点网络和分布式系统揉在一起。学生构建简单的并发文件服务器，协议类似 NFS，包含查找、读、写和取得属性等操作；全部文件存放在一个作为普通文件实现的磁盘镜像内。

可变方案非常多，既可规定不同磁盘格式，也可采用不同网络协议。
