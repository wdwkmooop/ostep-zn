# 第 1 章 关于本书的对话

> 英文原题：*A Dialogue on the Book*

<div class="dialogue" markdown>

**教授：** 欢迎阅读本书！它叫《操作系统导论：三个简单部件》，我会在这里教你需要了解的操作系统知识。大家都叫我「教授」；你是谁？

**学生：** 教授好！你大概已经猜到了，大家都叫我「学生」。我已经就位，准备学习！

**教授：** 很好。有什么问题吗？

**学生：** 当然有！为什么这本书叫「三个简单部件」？

**教授：** 这个简单。你看，Richard Feynman 做过一套很棒的物理学讲座……

**学生：** 哦！就是写《别闹了，费曼先生》的那个人，对吧？那本书太棒了！这本书也会像它一样好笑吗？

**教授：** 呃……这个嘛，不会。那本书确实很棒，我也很高兴你读过。希望这本书更像他的物理学讲义。那些讲义里的一些基础内容后来汇成了一本《六个简单的部分》。他讲的是物理；我们则要用「三个简单部件」来讲操作系统这个妙不可言的主题。这样安排很合适，因为操作系统的难度大约只有物理的一半。

**学生：** 好吧，我挺喜欢物理，这听起来应该不错。那三个部件是什么？

**教授：** 它们就是我们要学习的三个核心概念：**虚拟化(virtualization)**、**并发(concurrency)** 和**持久化(persistence)**。学习这些概念时，我们会全面了解操作系统如何工作，包括它如何决定接下来让哪个程序在 CPU 上运行，如何在虚拟内存系统中应对内存超载，虚拟机监控器如何工作，如何管理磁盘上的信息，甚至还会稍微谈谈如何构建一个能在部分组件发生故障时继续工作的分布式系统。诸如此类。

**学生：** 说真的，我完全不知道你在讲什么。

**教授：** 很好！这说明你来对课了。

**学生：** 我还有一个问题：学这些东西最好的办法是什么？

**教授：** 问得漂亮！当然，每个人都得自己摸索，不过换作是我，我会这样做：先去上课，听教授介绍材料；然后每周结束时读一遍这些讲义，让这些想法在脑子里扎得更深一点；过一阵子再读一遍（提示：考试之前！），把知识夯实。当然，你的教授肯定还会布置作业和项目，那些也得做。尤其是亲手编写真正的代码来解决真正问题的项目，最能把讲义里的想法付诸实践。正如孔子所说……

**学生：** 哦，我知道！「我听见了，就忘记了；我看见了，就记住了；我亲手做了，就理解了。」差不多是这样吧。

**教授：** （惊讶）你怎么知道我想说什么？！

**学生：** 顺理成章嘛。再说，我是孔子的忠实粉丝，更是荀子的超级粉丝——这句话其实更应该算在荀子头上[^1]。

**教授：** （目瞪口呆）好吧，我想我们会相处得非常愉快！真的，非常愉快。

**学生：** 教授——如果可以的话，最后再问一个问题。这些对话是干什么用的？我是说，这不就是一本书吗？为什么不直接讲内容？

**教授：** 啊，好问题，好问题！我觉得，偶尔从叙事里抽身出来想一想会很有用；这些对话就是留给我们这么做的时刻。所以，你和我要一起努力，把这些相当复杂的概念琢磨明白。你准备好了吗？

**学生：** 所以我们还得动脑子？行吧，我准备好了。反正我还能干什么呢？离开这本书，我也没多少生活可言。

**教授：** 真遗憾，我也一样。那么，开工吧！

</div>

[^1]: 据[这个网页](http://www.barrypopik.com/index.php/new_york_city/entry/tell_me_and_i_forget_teach_me_and_i_may_remember_involve_me_and_i_will_lear/)考证，儒家思想家荀子说过：「不闻不若闻之，闻之不若见之，见之不若知之，知之不若行之。」后来不知何故，这份智慧被安到了孔子头上。感谢 Rutgers 的 Jiao Dong 告诉我们这件事！
