# 附录 E 关于实验的对话

> 英文原题：*A Dialogue on Labs*

<div class="dialogue" markdown>
**学生：** 这是我们最后一次对话了吗？

**教授：** 我希望是！你知道吗，你越来越叫人头疼了！

**学生：** 是啊，我也很享受我们的谈话。这里讲什么？

**教授：** 讲你学习这些材料时应该做的项目；你知道，真正写程序，做点实事，而不是没完没了地说啊读啊。那才是真正的学习方式！

**学生：** 听起来很重要。您怎么不早点告诉我？

**教授：** 嗯，希望使用本书的人会在课程全过程中更早查看这一部分。要是没有，他们可真错过好东西了。

**学生：** 看起来是。那项目是什么样的？

**教授：** 有两类。第一类可以叫**系统编程项目(system programming project)**，在运行 Linux 的机器和 C 编程环境中完成。这种编程非常值得掌握，因为等你进入现实世界，很可能得亲手干一些这样的黑客活。

**学生：** 第二类呢？

**教授：** 第二类在真正的内核里面做，使用 MIT 开发的一个很酷的小型教学内核 xv6。它是把旧版 UNIX“移植”到 Intel x86 的产物，相当漂亮！在系统编程项目中，你写的是与内核交互的代码；在这些项目里，你会真正重写内核本身的一部分！

**学生：** 听起来很好玩！那一学期该做多少？您知道，一天就那么几个小时；而且各位教授似乎总忘了，我们学生要上四五门课，不是只有您这一门！

**教授：** 这里很灵活。有的课全做系统编程，因为它特别实用；有的全做 xv6 改造，因为它真能让你看清操作系统怎样工作；还有的——你大概猜到了——两者混合，先做一些系统编程，最后做 xv6。决定权在具体课程的教授手里。

**学生：** *（叹气）* 看来教授掌握全部控制权……

**教授：** 哪里有！不过，教授能行使的那一点控制权，确实是这份工作好玩的地方之一。决定布置什么作业很重要，而且没有教授会轻率对待。

**学生：** 听您这么说倒不错。我们该看看这些项目究竟讲什么了……

**教授：** 好。还有一件事：如果你对系统编程部分感兴趣，这里还有一篇 UNIX 与 C 编程环境的小教程。

**学生：** 听起来实用得都不像真的。

**教授：** 去看看吧。你知道，课程有时候就应该讲点有用的东西！
</div>
