# 致学生

> 英文原题：*To Students*

如果你是正在读这本书的学生，谢谢你！能为你在探索操作系统的路上提供一些材料，是我们的荣幸。我们俩都满怀深情地回忆起本科时代的一些教材（比如 Hennessy 和 Patterson 的经典计算机体系结构教材 [HP90]），也希望这本书能成为你心中一段美好的回忆。

你可能已经注意到，这本书免费，且可以在线获取。[^1] 这么做有个重要原因：教材通常太贵了。我们希望这本书是一波全新免费材料的第一本，帮助那些追求学问的人，无论他们来自世界哪个角落、无论愿意为一本书花多少钱。就算做不到那么多，它好歹也是一本免费的书，总比一本都没有强。

只要可能，我们还希望能把你指向书中许多材料的最初出处：那些多年来塑造了操作系统领域的伟大论文和人物。思想不是从空气里凭空抓来的；它们来自聪明而勤奋的人（其中有不少图灵奖得主[^2]），因此我们应当尽量颂扬这些思想和这些人。这样做，我们才有望更好地理解已经发生的那些革命，而不是把书写得仿佛这些想法一直就存在 [K62]。再者，也许这样的引用会鼓励你自己去深挖；读一读我们这个领域的著名论文，无疑是学习的最好方式之一。

[^1]: 这里岔开一句：我们此处用的"免费(free)"并不是指开源，也不意味着本书没有受常规保护、不受版权约束——它是受版权保护的！它的意思是，你可以下载这些章节，用它们来学习操作系统。那为什么不做成一本开源书，就像 Linux 是开源内核那样？嗯，我们相信一本书从头到尾保有**一致的声音**很重要，并为此下了功夫。你读它的时候，这本书应该有点像和一个正在给你讲解的人对话。这就是我们的做法。

[^2]: 图灵奖是计算机科学界的最高奖项；它就像诺贝尔奖，只不过你从没听说过它。
