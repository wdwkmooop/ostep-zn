# 附录 C 关于管程的对话

> 英文原题：*A Dialogue on Monitors*

<div class="dialogue" markdown>
**教授：** 所以，又是你，是吧？

**学生：** 我猜你现在已经相当疲惫了，毕竟，那个，你知道，年纪大了？不过 50 岁其实也没有那么老啦。

**教授：** 我没有 50 岁！事实上，我才刚满 40。不过天哪，我猜对你这种二十来岁的人……

**学生：** ……其实是 19 岁……

**教授：** *（唉）* ……对，19，随便吧。我猜在你眼里，40 和 50 看起来差不多。但相信我，完全不是一回事。至少我那些 50 岁的朋友是这么告诉我的。

**学生：** 总之……

**教授：** 啊，对！我们刚才要聊什么来着？

**学生：** 管程(monitor)。我不知道管程是什么，只知道 monitor 是摆在我面前这台电脑显示器的老派叫法。

**教授：** 对，这里说的是完全不同的东西。它是一种古老的并发原语，目的是把加锁自动融入面向对象程序。

**学生：** 那为什么不把它放进并发部分？

**教授：** 嗯，本书大部分内容都在讲 C 编程和 POSIX 线程库，而那里没有管程，这是一个原因。不过至少从历史角度看，还是有必要收入这个主题，所以它就出现在这里了，我猜。

**学生：** 啊，历史。那是给您这样的老年人准备的，对吧？

**教授：** *（怒目而视）*

**学生：** 哎呀，放轻松。我开玩笑的！

**教授：** 我已经等不及看你参加期末考试了……
</div>
