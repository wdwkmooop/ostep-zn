# 第 3 章 关于虚拟化的对话

> 英文原题：*A Dialogue on Virtualization*

<div class="dialogue" markdown>

**教授：** 于是，我们来到了操作系统三个部件中的第一个：**虚拟化(virtualization)**。

**学生：** 可什么是虚拟化呢，尊贵的教授？

**教授：** 想象我们有一只桃子。

**学生：** 一只桃子？（难以置信）

**教授：** 对，一只桃子。我们把它叫作**物理桃子(physical peach)**。可是现在有很多人都想吃这只桃子。我们希望摆到每个食客面前的，都是一只属于他自己的桃子，好让大家皆大欢喜。我们把交给食客的桃子叫作**虚拟桃子(virtual peach)**；不知怎么地，我们用一只物理桃子变出了许多只虚拟桃子。关键在这里：在这场幻象中，每个食客看起来都拥有一只物理桃子，实际上却并没有。

**学生：** 所以说，桃子其实是大家共享的，可自己压根儿不知道？

**教授：** 对！完全正确。

**学生：** 可是只有一只桃子啊。

**教授：** 是啊。然后呢……？

**学生：** 呃，要是我正和别人分一只桃子，我觉得我肯定能发现。

**教授：** 啊，说得好！不过人一多，事情就有转机了：大多数时候，他们不是在打盹，就是在忙别的；于是你可以趁机把桃子拿走，给另一个人吃一会儿。这样，我们就营造出了许多只虚拟桃子的幻象——人手一只！

**学生：** 听起来像一句糟糕的竞选口号。教授，你讲的其实是计算机，对吧？

**教授：** 啊，年轻的学徒，你想听一个更具体的例子。好主意！我们就拿最基本的资源——CPU——来说。假设系统中只有一颗物理 CPU（虽然如今经常有两颗、四颗甚至更多）。虚拟化所做的，就是拿这颗 CPU 开刀，让系统上运行的应用觉得自己面对的是许多颗虚拟 CPU。因此，每个应用都以为自己有一颗 CPU 可以独占，实际上却只有一颗。就这样，操作系统制造出了一场美丽的幻象：它把 CPU **虚拟化**了。

**学生：** 哇！听起来像魔法。再讲点！这是怎么做到的？

**教授：** 慢慢来，年轻的学生，时候到了自然会讲。看来你已经准备好开始了。

**学生：** 准备好了！嗯，差不多吧。必须承认，我有点担心你又要开始讲桃子。

**教授：** 别太担心；我压根儿就不喜欢桃子。于是，我们开始吧……

</div>
