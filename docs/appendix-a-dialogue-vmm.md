# 附录 A 关于虚拟机监控器的对话

> 英文原题：*A Dialogue on Virtual Machine Monitors*

<div class="dialogue" markdown>
**学生：** 所以，我们现在被困在附录里了，是吧？

**教授：** 对，就在你以为事情不可能变得更糟的时候。

**学生：** 嗯，那我们要聊什么？

**教授：** 一个重获新生的老话题：虚拟机监控器，也叫管理程序(hypervisor)。

**学生：** 哦，就像 VMware？挺酷的，我以前用过这类软件。

**教授：** 确实很酷。我们会学习 VMM 怎样给系统再加一层虚拟化，而且这一层在操作系统自己下面！说真的，这玩意既疯狂又神奇。

**学生：** 听起来不错。那为什么不把它放进本书前面的虚拟化部分？它不就该待在那里吗？

**教授：** 恐怕这超出了我们的工资级别。不过我猜原因是这样：那一部分的材料已经很多了。把这段关于 VMM 的小插曲挪到附录，任课教师就能自行决定讲还是跳过。但我认为应该讲，因为如果你能理解 VMM 怎样工作，就说明你对虚拟化确实理解得很透彻。

**学生：** 那好，开工吧！
</div>
