# 第 35 章 关于持久化的对话

> 英文原题：*A Dialogue on Persistence*

<div class="dialogue" markdown>
**教授：** 就这样，我们终于来到了操作系统四大……呃……三大支柱中的第三根：持久化。

**学生：** 您刚才说的是三根还是四根？第四根是什么？

**教授：** 没有第四根。就三根，年轻人，只有三根。咱们尽量把事情说简单点。

**学生：** 行吧。可是，尊贵又睿智的教授啊，什么叫持久化？

**教授：** 其实你大概知道它在日常语境里的意思，对吧？按字典的说法，就是“即使遇到困难或反对，仍坚定甚至执拗地继续做下去”。

**学生：** 有点像上您的课：确实得有几分执拗。

**教授：** 哈！没错。不过这里的持久化是另一回事。让我解释一下。想象你站在一片田野里，从树上摘下一个——

**学生：** （打断）我知道！桃子！从桃树上摘桃子！

**教授：** 我本来想说从苹果树上摘苹果。算了，就照你的来吧。

**学生：** （一脸茫然）

**教授：** 总之，你摘了一个桃子；准确地说，你摘了好多好多桃子，而且想让它们保存很久。毕竟威斯康星的冬天又漫长又残酷。你会怎么办？

**学生：** 办法应该不少。可以腌起来！也可以烤个派，或者熬成果酱。多好玩啊！

**教授：** 好玩？也许吧。可以肯定的是，要让桃子保存下去，你得多费不少工夫。信息也是如此：即使电脑崩溃、磁盘损坏或突然断电，仍要让信息保存下来——这是个困难又有趣的挑战。

**学生：** 这转场真顺。您越来越会了。

**教授：** 谢谢！你知道的，教授也永远欢迎几句好话。

**学生：** 我会尽量记住。看来该停止聊桃子，开始聊计算机了？

**教授：** 没错，时候到了……
